# Code of conduct

## The short version

Be straightforward and assume the other person is arguing in good faith.
Attack the claim, not the person making it.

## What that looks like here

This is a technical project about correctness, so disagreement is the normal
state and not a problem to be managed away. Saying "this is wrong, here is the
input that breaks it" is welcome from anyone about anything, including about
code we wrote and defended in public.

What is not welcome is personal abuse, harassment, discrimination, or
sustained disruption. Also unwelcome, and worth naming because it is more
common in technical spaces: treating a question as evidence that the asker
does not belong.

## Enforcement

Report to **github@harvestgroup360.com**. Reports are handled privately.
Depending on severity the response ranges from a private word to a permanent
block from the repository.

We would rather resolve something with a conversation than a ban, but a
project where people are afraid to ask is worse than a project with fewer
contributors.
